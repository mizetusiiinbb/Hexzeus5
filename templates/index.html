● فقط توکن کلودفلر را وارد کنید

🚀 استقرار ۱۰۰٪ خودکار بدون نیاز به گیت‌هاب یا ابزار جانبی

کافی است Cloudflare API Token خود را وارد کنید. سیستم به‌طور کاملاً خودکار سورس رسمی Z-E-U-S را دریافت کرده، برای شما یک نام تصادفی و پوششی می‌سازد، مسیر ادمین و کدهای آن را به صورت منحصربه‌فرد مبهم‌سازی (Polymorphic Obfuscation) می‌کند، پایگاه داده D1 اختصاصی را در حساب شما ایجاد کرده و ورکر را در کلودفلر منتشر می‌کند.

نیاز به دسترسی: Account:Workers Scripts (Edit) و Account:D1 (Edit) و User:Memberships (Read)
